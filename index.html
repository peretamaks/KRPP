Силабус дисципліни

Дисципліна «Командна розробка програмних проєктів» (КРПП) розрахована на формування професійних навичок організації спільних ІТ-проєктів за допомогою гнучких методологій (Agile, Scrum), автоматизації процесів, систем контролю версій та управління задачами у Jira.

Очікувані результати навчання:
  • Вміння планувати етапи проєкту, формувати Backlog та керувати Sprint у Jira.
  • Практичне застосування командних ролей (Product Owner, Scrum Master, Developer, QA).
  • Формування інцидентів, фіксація та супровід Bug Report і проведення Code Review.
Практичний стек: Atlassian Jira Software, Git / GitHub, HTML5, CSS3, JavaScript.

Параметри курсу

Обсяг дисципліни: 4 кредити ECTS (120 академічних годин)
Форма семестрового контролю: Диференційований залік / Екзамен
Аудиторні години: 16 год. лекцій, 32 год. лабораторних
